# Quiko - Global Style Guide for Google Stitch
## Use This Guide for ALL Screens

**Stitch URL**: https://stitch.withgoogle.com/

---

## 🎨 Design Foundation

**Copy this at the start of EVERY Stitch session:**

```
Brand: Quiko - peer-to-peer package delivery app
Platform: Mobile app (iOS/Android)

COLORS:
- Primary: #FFD93D (bright yellow) - for buttons, highlights, headers
- Secondary: #1A1A1A (deep black) - for text, secondary buttons
- Background: White (#FFFFFF)
- Success: #4CAF50 (green)
- Error: #F44336 (red)
- Gray scale: Light grays for borders and subtle backgrounds

TYPOGRAPHY:
- Headings: Bold, 24-32px
- Body text: Regular, 16px
- Small text/captions: 13-14px
- System font (San Francisco for iOS, Roboto for Android style)

COMPONENTS:
- Buttons: 48px height minimum (for easy tapping), rounded corners 12px
- Input fields: 48px height, 2px border, rounded 12px
- Cards: White background, subtle shadow, rounded 16px, 2px border
- Icons: 24px for standard size, 48px for hero/emphasis

SPACING:
- Page padding: 20px on left/right
- Between elements: 16px typically
- Between sections: 32px

LAYOUT:
- Mobile-first (design for 375px width, iPhone standard)
- Headers: 60px height, yellow background
- Single column layout (no complex multi-column grids)
```

---

## 📱 Screen Dimensions
- Width: 375px (iPhone standard)
- Common heights: 667px (iPhone SE), 812px (iPhone X), 844px (iPhone 12/13)
- Safe area: Account for notch/home indicator

---

## ✅ Accessibility Standards
- Minimum touch target: 48px × 48px
- Color contrast: 4.5:1 for text, 3:1 for large text
- WCAG 2.1 Level AA compliant

---

## 🎯 Design Principles
1. **Bold & Energetic**: High contrast, yellow pops, clear hierarchy
2. **Mobile-First**: Thumb-friendly, easy one-handed use
3. **Trust Signals**: Verification badges, ratings, security icons prominent
4. **Friendly but Professional**: Approachable copy, serious about safety

---

## 📝 Conversation Tips for Stitch

### Starting a Session
"Hi! I'm designing mobile screens for Quiko, a peer-to-peer package delivery app. Before we start, here are the brand guidelines to use for ALL screens: [paste global style above]"

### If Stitch Forgets Style
"Please maintain the Quiko style: Yellow (#FFD93D) primary, Black (#1A1A1A) text, 48px button height, 12px border radius, clean modern mobile design."

### Refining Designs
- "Make the button more prominent"
- "Increase spacing between cards to 16px"
- "Use bolder font for the heading"
- "Add more yellow to make it pop"
- "Reduce clutter, make it cleaner"

### Checking Elements
- "Does this button meet 48px minimum height?"
- "Is the text readable on this background?"
- "Is the spacing consistent with other screens?"
