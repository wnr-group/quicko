## 📝 How to Use

### For Each Section:
1. Open the section markdown file (e.g., `01_AUTHENTICATION.md`)
2. Copy the screen prompt
3. Paste into Stitch
4. Generate design
5. Review and iterate if needed
6. Export/save the result
7. Move to next screen in section
8. When section done, move to next section file

### Tips:
- **Always start with Global Style Guide** in each Stitch session
- **Work linearly** (Section 1 → 2 → 3... don't jump around)
- **Save exports** with screen numbers (e.g., "Screen_01_Splash.png")
- **Note changes** if you deviate from prompts (document customizations)
